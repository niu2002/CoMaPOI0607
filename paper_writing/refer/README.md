# Supporting materials

The only English manuscript source is
`../english/GeoSemID_TITS.tex`. Compile it with PDFLaTeX, BibTeX, and two
additional PDFLaTeX passes.

- `references.bib`: the manuscript bibliography.
- `figures/`: figure PDFs referenced by the English source.
- `mock_experiments/`: clearly labeled planning-only Mock tables and CSV files.
- `scripts/`: scripts used to generate the Mock figures and consistency checks.
- `reports/` and `AUTHOR_INPUTS_REQUIRED.md`: project audits and remaining
  author-supplied settings; they are not manuscript text.
- `archive/`: prior standalone method material retained for traceability, not
  part of the build.
